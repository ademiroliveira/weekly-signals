# weekly-signals

AO's weekly **Self-Custody & Sovereignty Signal Report**, archived week by week and used to write articles on UX and product design.

## How it works

```
Monday (scheduled)      /weekly-report   8 research agents → 2 verifiers → signals/YYYY-MM-DD.md → live artifact → push
Whenever you're writing /connect         all weeks → themes/        (recurring threads, tensions, gaps)
                        /angle           themes → articles/ideas.md (claims with evidence)
                        /draft <angle>   → articles/drafts/         (in AO's voice, every claim cited)
```

- `signals/`: one report per week. Append-only; nothing is ever overwritten.
- `themes/`: running design questions that show up across weeks.
- `articles/`: ideas → drafts → published.
- `.claude/agents/`: `key-management`, `hardware-enclaves`, `recovery-identity`, `regulatory-policy`, `sovereign-adoption`, `threat-vectors`, `agentic-wallets`, `wallet-ux`, `verifier`.
- `CLAUDE.md`: hard constraints, source hierarchy and writing voice, shared by everything.

Open the folder in Claude Code (or a Cowork session linked to this repo) and run any command.
