# Self-Custody & Sovereignty Signal Report — Week of Nov 3 – 9, 2026

## Top 3 Signals

### 1. FinCEN and the Federal Reserve Board Withdraw the Proposed Recordkeeping and Travel Rule Amendment for Convertible Virtual Currencies
🟠 Emerging · formal · regulatory · regulation · [Regulatory filing]

**Summary:** FinCEN announced on November 6, 2026 the withdrawal of a proposed rule that would have amended the Recordkeeping and Travel Rule for convertible virtual currencies and lowered the threshold for funds transfers and transmittals that begin or end outside the United States. The page says the withdrawal is joint with the Federal Reserve Board of Governors.
**Filter:** A pending proposal that would have changed the reporting terms for convertible virtual currency transfers is withdrawn, which affects what record-keeping obligations transfer counterparties face.
**Source:** [Regulatory filing] https://www.fincen.gov/news/news-releases/fincen-announces-withdrawal-proposed-rule-related-recordkeeping-and-travel-rule · 2026-11-06

### 2. Core Lightning 26.06.10 Is a Security Release Covering Dual-Funding, Splicing, Onchain HTLC Resolution and Other Fixes
🟠 Emerging · formal · technical · threat, key-mgmt · [GitHub release]

**Summary:** The release notes list fixes for signature checks on the peer's tx_signatures (dual funding and splicing), HTLC resolution in onchaind, gossip resource limits, and further fixes in connectd, runes/commando, plugin hooks and hsmd. The notes say the maintainers withheld the tests for the security fixes, that there is no embargo period, and that they strongly encourage upgrading. Optech #430 also reports the release.
**Filter:** People who run their own Lightning node hold their channel funds directly, so a security release in the code paths that handle those channels is a patch they must apply themselves.
**Source:** [GitHub release] https://github.com/ElementsProject/lightning/releases/tag/v26.06.10 · 2026-11-04
**Also:** https://bitcoinops.org/en/newsletters/2026/11/06/

### 3. LND v0.21.6-beta and v0.20.7-beta Disable MPTCP Listeners by Default as a Mitigation for Linux Kernel CVE-2026-98432 (Optech #430)
🟠 Emerging · formal · technical · threat · [Protocol blog]

**Summary:** Optech #430 says LND v0.21.6-beta and v0.20.7-beta include the mitigation for CVE-2026-98432, a Linux kernel vulnerability, by disabling Multipath TCP listeners by default; Go 1.24 and later enable them by default on supported Linux systems. Optech says the LND change does not fix the kernel bug and advises Linux operators to upgrade, disable MPTCP on the host and install a patched kernel. The LND release notes call it "a mitigation, not a fix: the kernel patch is the only fix" and say Windows and macOS are not affected.
**Filter:** Operators who run a Lightning node on Linux depend on a patched host kernel as well as on the node software.
**Source:** [Protocol blog] https://bitcoinops.org/en/newsletters/2026/11/06/ · 2026-11-06
**Also:** https://github.com/lightningnetwork/lnd/releases/tag/v0.21.6-beta
